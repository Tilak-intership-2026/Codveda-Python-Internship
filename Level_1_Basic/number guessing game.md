Number Guessing Game - Codveda Internship (Level 1)
This is an interactive command-line game where the user attempts to guess a randomly generated number between 1 and 100. The program provides real-time feedback ("Too High" or "Too Low") and limits the number of attempts to ensure a challenging experience.
 Features
Random Number Generation: Uses Python's random module to generate a secret number.
Attempt Limit: Users have a maximum of 10 attempts to guess correctly.
Real-time Feedback: Guides the user with hints after every incorrect guess.
Input Validation: Handles non-numeric inputs gracefully without crashing.
Working Structure & Flow Chart
The game logic revolves around a while loop that continues until the user guesses correctly or runs out of attempts.
