 Simple Calculator - Codveda Internship (Level 1)
This project is a basic Python calculator designed to perform four primary arithmetic operations: Addition, Subtraction, Multiplication, and Division. It focuses on modular programming by using separate functions for each operation and includes robust error handling for invalid inputs and division by zero.
 Features
Modular Design: Separate functions for add, subtract, multiply, and divide.
User Interaction: Takes two numbers and an operation choice from the user.
Error Handling:
Prevents crashes on non-numeric inputs (ValueError).
Handles division by zero gracefully with a custom error message.
 #============================================#
 Learning Outcomes
Understanding of Python Functions and parameters.
Implementation of Conditional Statements (if-elif-else).
Mastery of Exception Handling (try-except) for robust user input.
